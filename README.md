# Music Ear Training App

Tone.js を利用したブラウザ向けの音楽イヤートレーニング（音感トレーニング）アプリケーションです。
リアルなピアノ音源（Salamander Grand Piano）を使用し、相対音感やコード構成音の理解を深めることができます。

## 概要

このアプリケーションには、以下の2つの主要なゲームモードが搭載されています。

1. **インターバル（音程）当てモード**
   2つの音を聴き、その音程差（半音いくつ分か、完全5度など）を当てるトレーニングです。
2. **コード構成音当てモード**
   指定されたルート音とコードの種類（メジャー、マイナー、セブンス、ナインスなど）から、そのコードに含まれる構成音を選択して当てるトレーニングです。

## 主な機能

- **リアルな音源再生**: Tone.js のサンプラー機能を利用し、高音質なピアノサウンドで問題を出題します。
- **柔軟な設定項目**:
  - **ルート音設定**: ランダム、前回のルート音に固定、または特定の音階に固定。
  - **インターバルの方向**: 上行、下行、またはランダム。
  - **最大半音数**: 出題される音程の範囲（最大オクターブ等）を制限可能。
  - **コードの複雑さ**: トライアド（3和音）、セブンス（4和音）、ナインス（5和音）から選択可能。
  - **再生方法**: 音程を順次再生（メロディック）するか、同時再生（ハーモニック）するかを選択可能。
- **成績トラッキング**: 正答数、出題数、および正答率をリアルタイムで表示します。
- **リプレイ機能**: 問題の音（ペア、ルート音のみ、ターゲット音のみ）を何度でも聴き直すことができます。

## 使用技術

- HTML / CSS (UI構築)
- JavaScript (ES6+)
- [Tone.js](https://tonejs.github.io/) (Web Audio API を利用した音声制御とサンプラー)

## 使い方

1. `index.html`（本スクリプトを読み込んでいるHTMLファイル）をWebブラウザで開きます。
   ※ Tone.js などの外部スクリプトや音声ファイルを読み込むため、ローカルサーバー（Live Serverなど）経由での起動を推奨します。
2. 画面上の **「Start Audio」** ボタンをクリックして、Tone.jsのオーディオコンテキストを開始します。
3. **ゲームモード**（インターバル / コード構成音）を選択します。
4. お好みに合わせて各種設定（ルート音、出題範囲など）を調整します。
5. 音声が再生されたら、画面に表示される選択肢（ボタン）から正解だと思うものを選んでクリックします。
   - _コードモードの場合_: 複数の音を選択してから「解答する（submitChord）」ボタンを押します。
6. フィードバック（正解・不正解）が表示されます。「Next（新しい問題）」ボタンを押して次の問題に進んでください。
